**الحالة: متاح من الشيفرة المصدرية.** اختُبر على جهاز Mac بمعالج Apple Silicon، بما في ذلك المشاركة مع جهاز Android لوحي على شبكة Wi-Fi نفسها. لا يوجد تطبيق جاهز — يعمل RTW من الطرفية.

## المتطلبات

- macOS على Apple Silicon أو Intel
- أدوات سطر أوامر Xcode — توفّر `git` وPython 3 ‏(`xcode-select --install`)
- [Homebrew](https://brew.sh)
- مساحة تخزين للمحتوى (راجع [تجهيز مكتبتك](/ar/docs/preparing-your-library/))

## التثبيت

```bash
git clone https://github.com/eslam-mahmoud/reinvent-the-wheel.git
cd reinvent-the-wheel
./rtw setup
./rtw start
```

يقوم `./rtw setup` بما يلي:

1. يثبّت **nginx** عبر Homebrew إن لم يكن موجودًا.
2. ينزّل **kiwix-tools** الخاصة بـmacOS من Kiwix إلى `state/bin`.
3. ينزّل ملفات JavaScript والخطوط والأيقونات الخاصة بعارض الخرائط إلى `web/vendor`.
4. يكتب الإعدادات في `state/conf`، وينشئ شهادة HTTPS موقّعة ذاتيًا ومجلدات المحتوى.
5. يطلب كلمة مرور للمشرف.

يمكن تشغيله مجددًا بأمان؛ فهو لا يمسّ محتواك ولا كلمة المرور.

## أين توجد الأشياء

| المسار | المحتوى |
|---|---|
| `content/` | مكتبتك — مجلد لكل قسم |
| `state/conf/` | الإعدادات المولَّدة وشهادة HTTPS وبصمة كلمة المرور |
| `state/logs/` | السجلات (`./rtw logs admin`، `./rtw logs kiwix`) |

## العناوين

| العنوان | الاستخدام |
|---|---|
| `http://127.0.0.1:8080` | على جهاز Mac نفسه |
| `http://<mac-ip>:8080` | الأجهزة الأخرى على شبكة Wi-Fi نفسها |
| `https://<mac-ip>:8443` | العنوان نفسه عبر HTTPS — مطلوب لعرض الموقع على صفحة الخريطة |

## التحديث

```bash
./rtw update
```

يجلب أحدث إصدار من GitHub ويعيد تشغيل الخدمات.

## القيود

- يجب أن يبقى Mac مستيقظًا أثناء تقديم المكتبة. امنع السكون من إعدادات النظام، أو شغّل `caffeinate -d` في طرفية أخرى.
- قد يطلب macOS السماح باتصالات واردة لـnginx في أول مرة تتصل فيها أجهزة أخرى.
