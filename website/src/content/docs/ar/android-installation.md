**الحالة: متاح من الشيفرة المصدرية.** اختُبر بالكامل على جهاز Redmi Pad 2 Pro ‏(Android 16): التثبيت من GitHub بأمر واحد، وتقديم كل الأقسام (بما فيها ويكيبيديا العربية بحجم 8.4 غيغابايت)، ونسخ المحتوى من Mac عبر USB، وفتح المكتبة من أجهزة أخرى — على شبكة Wi-Fi نفسها وعبر نقطة اتصال الجهاز اللوحي — وتنزيل حِزم المعرفة مباشرة على الجهاز بالأمر `rtw fetch`. نرجو [إخبارنا بما يعمل على جهازك](/contribute/).

يعمل RTW داخل **Termux**، وهو تطبيق طرفية لنظام Android. لا حاجة إلى صلاحيات root ولا إلى نظام معدّل ولا إلى تطبيق RTW منفصل.

## المتطلبات

- جهاز ARM بنظام 64 بت ‏(`arm64-v8a`)
- **Termux.** نسخة F-Droid / GitHub تدعم Android 7 فما فوق. ونسخة Google Play التي اختبرناها تتطلب Android 12L أو أحدث.
- مساحة تخزين حرة للمحتوى
- يُنصح بذاكرة 4 غيغابايت أو أكثر

## التثبيت من GitHub (دون حاسوب)

افتح Termux وشغّل:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/eslam-mahmoud/reinvent-the-wheel/main/bootstrap.sh)"
```

يقوم المثبّت بما يلي:

1. يطلب **إذن الوصول إلى التخزين** — اضغط *سماح*. يعيش المحتوى في المجلد المشترك `RTW` ‏(`/sdcard/RTW`).
2. يثبّت `nginx` و`kiwix-tools` و`python` و`git` وبعض الأدوات المساعدة عبر `pkg`.
3. ينسخ المشروع إلى `~/rtw`.
4. ينزّل ملفات عارض الخرائط ويكتب الإعدادات.
5. يطلب منك اختيار **كلمة مرور للمشرف**.

ثم:

```bash
rtw start
```

## التثبيت من Mac عبر USB

مفيد حين لا يتوفر إنترنت على الجهاز. فعّل *تصحيح أخطاء USB* ووصّل الجهاز، ثم على Mac:

```bash
./rtw push
```

ثم في Termux:

```bash
termux-setup-storage
bash ~/storage/shared/RTW/_setup/server/install-termux.sh
rtw start
```

## إبقاؤه يعمل

- **البطارية:** إعدادات Android ← التطبيقات ← Termux ← البطارية ← *بلا قيود*. وإلا فقد يوقف Android الخادم في الخلفية.
- يحجز `rtw start` قفل تنبيه (wakelock) في Termux.
- **التشغيل عند الإقلاع** يتطلب الإضافة المنفصلة *Termux:Boot*، مثبّتة من المصدر نفسه الذي ثبّت منه Termux. المثبّت يضع سكربت الإقلاع مسبقًا.

## شاركه

فعّل نقطة الاتصال في Android وأعطِ الناس العنوان الذي يطبعه `rtw start`. راجع [المشاركة عبر Wi-Fi المحلية](/docs/sharing-over-local-wifi/).

## قيود معروفة

- المنافذ الأقل من 1024 غير متاحة دون root، لذا تستخدم المكتبة المنفذ `8080` ‏(و`8443` لـHTTPS).
- التخزين الخارجي عبر USB غير مدعوم بعد — راجع [التخزين الخارجي عبر USB](/docs/external-usb-storage/).
