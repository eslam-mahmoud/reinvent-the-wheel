بعد تنزيل المحتوى، لا يحتاج RTW إلى أي اتصال بالإنترنت.

## الأوامر

```bash
rtw start      # تشغيل كل شيء وطباعة العناوين
rtw stop
rtw restart
rtw status     # الخدمات وحجم المحتوى والعناوين
rtw address    # العناوين التي تستطيع الأجهزة الأخرى فتحها الآن
rtw help       # كل الأوامر مع أمثلة
rtw logs       # متابعة سجل أخطاء خادم الويب (وأيضًا: admin وkiwix)
```

على Mac، شغّلها من مجلد المشروع بالصيغة `./rtw …`. وعلى Android تعمل أيضًا الأوامر `rtw-start` و`rtw-stop` و`rtw-status` و`rtw-passwd`.

## ما الذي يعمل

| الخدمة | المنفذ | الغرض |
|---|---|---|
| nginx | 8080 و8443 | الصفحات والملفات، والبوابة الأمامية لكل ما عداها |
| kiwix-serve | 8081 (محلي فقط) | ويكيبيديا وملفات ZIM الأخرى |
| واجهة الإدارة | 8082 (محلي فقط) | الرفع وإدارة المحتوى |

لا يمكن الوصول من الأجهزة الأخرى إلا إلى nginx.

## كلمة مرور المشرف

رفع المحتوى وإدارته يتطلبان كلمة مرور المشرف. إن نسيتها، أعد تعيينها **على الجهاز نفسه**:

```bash
rtw passwd
```

الوصول إلى طرفية الجهاز هو ما يثبت أنك المالك. ويسري التغيير فورًا.

## تحقّق قبل أن تحتاج

قبل الاعتماد على المكتبة، أطفئ Wi-Fi وبيانات الجوال وجرّبها: افتح بعض مقالات ويكيبيديا وكتابًا وملاحظة والخريطة. إصلاح أي نقص أسهل بكثير وأنت ما زلت متصلًا.
