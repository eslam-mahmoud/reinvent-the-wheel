هذا أسرع طريق: جهاز Mac مع أدوات سطر أوامر Xcode (لـ`git` وPython 3) و[Homebrew](https://brew.sh). أما Android فراجع [التثبيت على Android](/docs/android-installation/).

## ١. احصل على الشيفرة

```bash
git clone https://github.com/eslam-mahmoud/reinvent-the-wheel.git
cd reinvent-the-wheel
```

## ٢. الإعداد

```bash
./rtw setup
```

يثبّت هذا الأمر nginx ‏(عبر Homebrew) وخادم Kiwix، وينزّل ملفات عارض الخرائط، ويكتب الإعدادات، ثم يطلب منك اختيار **كلمة مرور للمشرف** — تُستخدم لرفع المحتوى وإدارته من المتصفح.

## ٣. التشغيل

```bash
./rtw start
```

افتح `http://127.0.0.1:8080` في المتصفح. يطبع الأمر أيضًا عنوانًا مثل `http://192.168.0.3:8080` يمكن للأجهزة الأخرى على شبكة Wi-Fi نفسها فتحه.

## ٤. أضف المحتوى

وأنت متصل بالإنترنت:

```bash
./rtw fetch             # اختر حِزم المعرفة — لا يُثبَّت إلا ما تختاره
./rtw fetch wikipedia   # ويكيبيديا العربية، نص فقط — نحو 8.4 غيغابايت
./rtw fetch maps        # خريطة متجهية للسعودية ومصر — نحو 1.1 غيغابايت
./rtw fetch osmand      # تطبيق الملاحة OsmAnd وخرائطه للهواتف
./rtw fetch bitchat     # Bitchat — تطبيق دردشة عبر البلوتوث دون إنترنت
```

أو ارفع ملفاتك الخاصة من `/admin/`. بعد وصول ملف ويكيبيديا جديد، شغّل `./rtw restart`.

> أوامر الجلب المدمجة تستهدف حاليًا ويكيبيديا العربية وخريطة للسعودية ومصر — وهي احتياجات أول تجربة نشر. أي لغة أو منطقة تعمل أيضًا؛ راجع [استخدام Kiwix وملفات ZIM](/docs/using-kiwix-and-zim-files/) و[تجهيز مكتبتك](/docs/preparing-your-library/).

## أوامر يومية

```bash
./rtw status     # ما الذي يعمل، وحجم المحتوى
./rtw stop
./rtw passwd     # تعيين كلمة مرور المشرف أو إعادة تعيينها
```
