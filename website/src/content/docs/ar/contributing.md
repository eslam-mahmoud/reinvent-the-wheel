RTW مشروع مفتوح المصدر وفي بداياته. كل أنواع المساعدة مفيدة، وكثير منها لا يتطلب كتابة الشيفرة. راجع [ساهم](/ar/contribute/) لنظرة عامة.

## أخبرنا بما يعمل على جهازك

تقارير الأجهزة ثمينة بشكل خاص الآن. افتح بلاغًا يتضمن:

- طراز الجهاز وإصدار Android أو macOS
- مصدر تثبيت Termux ‏(F-Droid أو GitHub أو Google Play)
- ما نجح وما لم ينجح، ومخرجات `rtw status`

## التطوير

```bash
git clone https://github.com/eslam-mahmoud/reinvent-the-wheel.git
cd reinvent-the-wheel
./rtw setup
./rtw start
```

صفحات المكتبة في `web/` هي HTML وJavaScript عادية — عدّل وأعد التحميل. سلوك الخادم موجود في `server/`. راجع [البنية](/ar/docs/architecture/).

## حسّن هذا التوثيق

يعيش هذا الموقع في `website/` داخل المستودع نفسه. كل صفحة توثيق ملف Markdown في `website/src/content/docs/` — الإنجليزية في `en/` والعربية في `ar/`. وفي أسفل كل صفحة رابط *عدّل هذه الصفحة*.

## إرشادات

- فضّل دمج أداة مفتوحة المصدر موجودة على كتابة أداة جديدة.
- حافظ على العمل دون اتصال: لا اتصالات بخدمات خارجية أثناء التشغيل.
- كن صادقًا في التوثيق: علّم الخطوات غير المختبرة بأنها كذلك.
- احترم رخص المحتوى — لا تضف مواد الأطراف الأخرى إلى المستودع.
